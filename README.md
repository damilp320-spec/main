# 🧠 Nexus AI Hub

**Стильное десктоп-приложение для Windows 11, которое устанавливает, настраивает и запускает автономных AI-агентов прямо на вашем ПК.**

Все нейросети работают **локально** (через [Ollama](https://ollama.com)), могут **полностью взаимодействовать с компьютером** (PowerShell, файлы, приложения), имеют **доступ в интернет** (поиск, загрузка страниц), выполняют задачи по **расписанию** и понимают **голосовые команды**.

### 🎯 Максимально дружелюбный интерфейс

- 🚀 **Онбординг-мастер** при первом запуске: приветствие → выбор сценариев → определение «железа» → установка моделей в один шаг → готово. ИИ работает за пару минут без настройки.
- ⌨️ **Командная палитра `Ctrl+K`** — мгновенный доступ к любому разделу и действию, как в VS Code.
- 🌍 **Мультиязычный интерфейс** — русский, English, Українська, Español, Deutsch, 中文 (переключение в настройках).
- 💽 **Выбор диска для нейросетей** — модели можно ставить на любой диск/папку (через `OLLAMA_MODELS`), с быстрым выбором среди доступных дисков и их свободного места.
- 🎬 **Сценарии использования** — готовые наборы агентов и автоматизаций в один клик (утренний помощник, контент-студия, рабочее место разработчика и др.).
- 🧩 **Галерея из 30+ агентов** и **40+ готовых промптов** с поиском.
- 🎨 **Темы оформления** — светлая/тёмная и 8 акцентных цветов.
- ⚙️ **Расширенные настройки** — автозапуск, старт в трее, уведомления, скорость речи, авто-прослушивание, креативность (temperature), глубина автономии, модель по умолчанию, полный доступ к диску, сброс настроек.
- 📊 **Дружелюбная загрузка моделей** — прогресс со скоростью, ETA и объёмом.
- 📤 **Импорт/экспорт агентов** файлом `.nexus.json`.

> ⭐ Pro-режим временно отключён — все функции доступны бесплатно и без ограничений.

### 🔐 Безопасность

- **Песочница файловой системы**: по умолчанию агенты работают только в рабочем пространстве; выход за его пределы и запись в системные каталоги (`Windows`, `Program Files`, `/etc` и др.) заблокированы. Полный доступ к диску включается явно в настройках.
- **Усиленный фильтр команд**: разрушительные операции (`format`, `diskpart`, `rm -rf`, `Remove-Item -Recurse`, fork-бомбы, `shutdown` и десятки других паттернов) блокируются регулярными выражениями, а не простым поиском подстроки.
- **Шифрование секретов**: пароли и SSH-ключи серверов шифруются через OS-хранилище (Electron `safeStorage`), а не лежат в открытом виде.
- **Изоляция окна**: запрет внешней навигации и всплывающих окон, открытие ссылок только в системном браузере и только по `http(s)`; `contextIsolation`, выключенный `nodeIntegration`, строгий CSP.

### 🧠 Умная долговременная память

Чтобы контекст «жил долго, но не забивался ненужным»:
- после каждого диалога агент **сам выделяет важные факты** (предпочтения, пути, серверы, договорённости) и сохраняет их;
- факты **дедуплицируются**, ранжируются по ценности и ограничены лимитом (мусор вытесняется);
- длинная история чата **сжимается в краткое резюме**, а свежие сообщения остаются как есть;
- память можно просмотреть, дополнить вручную или очистить (кнопка 🧠 в чате).

### 🧱 Студия плагинов Minecraft

Создаёт готовый Maven-проект (Paper API) из шаблонов *basic / command / listener*, генерирует `pom.xml`, `plugin.yml` и Java-класс, затем компилирует в `.jar`. Агент-разработчик умеет итеративно править код по логам ошибок сборки. Требуется JDK 17+ и Maven (приложение проверяет их наличие и подсказывает команды `winget`).

### 🖥️ Удалённые серверы (SSH/SFTP)

Подключения (пароль или приватный ключ) сохраняются локально. Доступны: навигация по каталогам, чтение и редактирование конфигов прямо на сервере, выполнение команд. Агент-администратор работает с серверами через инструменты `remote_*`.

## 🔬 Ресерч: какие нейросети выбраны и почему

Для обычного ПК ключевые критерии — **скорость**, **умеренные требования к ОЗУ** и **надёжный tool-calling** (без него агент не сможет управлять компьютером). На основе обзоров локальных моделей 2026 года отобраны:

| Модель | Размер | ОЗУ | Почему |
|---|---|---|---|
| **Llama 3.2 3B** (Meta) ★ | 2.0 ГБ | 8 ГБ | Быстрая, есть tool-calling — лучший «мозг» агента на слабом ПК. |
| **Qwen 2.5 7B** (Alibaba) ★ | 4.7 ГБ | 16 ГБ | Один из лучших открытых вариантов для агентов: стабильные вызовы инструментов. |
| **Gemma 2 9B** (Google) | 5.4 ГБ | 16 ГБ | Сильное качество ответов. |
| **Mistral 7B** | 4.1 ГБ | 16 ГБ | Очень быстрая, поддерживает инструменты. |
| **Phi 3.5 Mini** (Microsoft) | 2.2 ГБ | 8 ГБ | Работает даже на ноутбуках с 8 ГБ. |
| **Qwen 2.5 Coder 7B** | 4.7 ГБ | 16 ГБ | Для агента-программиста. |
| **Nomic Embed** | 0.3 ГБ | 8 ГБ | Эмбеддинги для памяти/поиска по документам (RAG). |

Приложение **само определяет объём ОЗУ** и предлагает подходящий набор: ≤8 ГБ → Llama 3.2 + Phi; 16 ГБ → Qwen 2.5 + Llama 3.2; больше → добавляет Gemma и Coder.

Источники ресерча: обзоры локальных моделей и агентов 2026 (Ollama-модели для 8/16 ГБ, открытые агенты для управления Windows — Open Interpreter, UI-TARS, AgentS, OpenClaw).

## ❓ Вопросы и ответы (которые задают чаще всего)

**1. Это правда работает офлайн?**
Да. Модели крутятся на вашем ПК через Ollama. Интернет нужен только инструментам `web_search`/`http_get`, когда вы сами об этом просите.

**2. Безопасно ли давать ИИ доступ к PowerShell?**
Агент работает в каталоге-песочнице (`~/NexusAI-Workspace`), а разрушительные команды (`format`, `shutdown`, `rm -rf /`, `diskpart`…) жёстко блокируются. Выполнение команд можно полностью отключить в настройках.

**3. Какой ПК нужен?**
Минимум 8 ГБ ОЗУ (модели 3B). Комфортно — 16 ГБ. Видеокарта ускоряет, но не обязательна — Ollama умеет работать на CPU.

**4. Чем это отличается от ChatGPT?**
Полная приватность (данные не уходят в облако), отсутствие подписки, и главное — агент реально **управляет вашим компьютером**, а не только пишет текст.

**5. Как агент «взаимодействует с компьютером»?**
Через набор инструментов: запуск команд, чтение/запись файлов, открытие приложений и URL, поиск в интернете, системная информация, уведомления. Модель сама решает, какой инструмент вызвать.

**6. Можно ли добавить свою модель?**
Да — установите любую модель Ollama, и она появится в списке выбора при настройке агента.

**7. Что значит «уровень автономии»?**
*Только чат* — без доступа к ПК. *Сбалансированный* — инструменты по необходимости. *Автономный* — многошаговые задачи (до 12 шагов) с самопроверкой.

**8. Голосовой ассистент на каком языке?**
Русский (`ru-RU`) для распознавания и синтеза, используется встроенный движок Windows.

## 🚀 Запуск и сборка

```bash
npm install        # установка зависимостей
npm start          # запуск в режиме разработки
npm run icon       # сгенерировать иконку приложения (build/icon.ico, build/icon.png)
npm run dist:win   # компиляция: установщик (NSIS) + portable .exe → dist/
npm run dist:linux # сборка AppImage для Linux → dist/
```

Готовый `.exe` собирается автоматически в **GitHub Actions** (`.github/workflows/build.yml`) на каждом пуше — артефакт `nexus-ai-hub-windows`. При пуше тега `v*` установщик публикуется в **GitHub Release** (черновик). Фирменная иконка генерируется скриптом `scripts/gen-icon.js` без внешних зависимостей.

> 💰 Модель монетизации (Freemium / Pro / облачный мост / маркетплейс) описана в [MONETIZATION.md](MONETIZATION.md).

> Перед первым запуском агентов нажмите **«Быстрая установка»** на главном экране — приложение само поставит Ollama и нужные модели.

## 🏗️ Архитектура

```
src/
├── main/                 # Главный процесс Electron
│   ├── main.js           # окно, трей, IPC, горячие клавиши
│   ├── ollama.js         # клиент локального Ollama API (стриминг + tool-calling)

│   ├── agent.js          # движок автономных агентов (цикл модель↔инструменты)
│   ├── system.js         # инструменты управления ПК + системная информация
│   ├── scheduler.js      # планировщик задач (включение/интервал/расписание)
│   ├── voice.js          # координатор голосового ассистента
│   ├── memory.js         # умная долговременная память (факты + сжатие истории)
│   ├── minecraft.js      # студия плагинов Paper/Spigot + компиляция Maven
│   ├── remote.js         # SSH/SFTP: файлы, конфиги, команды на серверах
│   ├── translator.js     # перевод больших данных с разбивкой на чанки
│   ├── licensing.js      # тарифы Free/Pro, ключи, trial, гейтинг функций
│   ├── store.js          # JSON-хранилище конфигурации
│   └── preload.js        # безопасный мост contextBridge
└── renderer/             # Интерфейс
    ├── index.html
    ├── styles.css        # стильная тёмная тема
    └── app.js            # вся логика UI, чат, голос (Web Speech API)
```
